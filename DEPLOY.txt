Gym Tracker V6.3 — PWA-ready deployment package

This build is based on the passed V5.8 Cloud/Sync checkpoint.

To use on iPhone:
1. Host this folder on an HTTPS static website.
2. Open the URL in Safari on iPhone.
3. Share > Add to Home Screen.
4. Open from the Home Screen and sign in to Gym Tracker Cloud.

Important:
- Supabase authentication and sync remain online-only.
- The app shell and exercise artwork are cached for offline opening.
- Sync still requires user approval.

V6.0: startup/reload no longer creates a local modification timestamp.

V6.1: mobile navigation uses More for Library and Cloud; floating Cloud shortcut removed.

V6.2: bike/cross-trainer time, level and program editable during a visit; completed cardio settings saved in visits; mobile cloud-status pill centred.

V6.2.1: fixed build migration so unfinished sessions from prior builds are cleared without altering exercises, visits, cardio defaults or cloud data.

V6.2.2: added Cancel visit with confirmation; discards only the active visit and does not create a visit record or revert saved exercise/cardio defaults.

V6.3: added About page to mobile More menu and desktop navigation; moved visible version/build information into About.
